【产品定位·最高优先级认知】
冲浪阅读**不是商业化小说平台、不追求书库丰富度**，而是一个「**粉丝向 IP 宇宙同人小说阅读社区**」：
- 现有约 5 本书同属一个 IP 宇宙世界观，字数合计约 800 万字；读者均冲着该 IP 宇宙而来。
- 不焦虑书库数量；roadmap 重心是「打好地基（秒开/离线/稳定/社区）」，内容自然增长。
- 同人内容未来仍走冲浪阅读自有后端，**绝不牵扯主站 DB**（物理隔离铁律）。

## 2.1 安卓 App 架构
- 技术栈：Kotlin + Jetpack Compose（M3 主题，M2 仅用于 pullrefresh）；Retrofit+OkHttp 网络；Coil 图片；
  DataStore 设置持久化；Room 本地书架；KSP（非 kapt，Kotlin 2.0 下避免吞编译错误）。
- 分层（清晰的两层，无 DI 框架）：
  - data/   ：仓库层（object/class XxxRepository 单例）+ 网络客户端（BackendApi/AuthApi）+ 本地存储（*Store）+ 设置（AppSettings/ReaderSettings）。
  - ui/     ：每个功能一个包，含 Screen（页面）+ ViewModel（状态/业务）+ 复用组件。
- 入口链：MainActivity.onCreate → AppContext.init → CrashLogger.install → enableEdgeToEdge()
          → setContent { AppRoot() }。
- 导航：ui/AppRoot.kt 的 `object Routes`（路由常量 + 拼参函数） + NavHost 内 `composable(...)`。
  底层导航（home/booklibrary/bookshelf/community/booklists/settings）显示底部栏；
  detail/reader/character/creator/admin 等为覆盖式全屏，不显底栏。
- 数据流模式：ViewModel 暴露 `uiState: StateFlow` + `toast` 事件；业务调用 `XxxRepository` →
  Retrofit 挂起函数返回 `Result<T>`；登录态/禁言由 AppContext + AppSettingsRepository 提供。

## 2.2 后端架构
- Next.js 15 App Router：`app/api/<domain>/<route>/route.ts` 每个文件一个端点（GET/POST…）。
  `dynamic = "force-dynamic"`；Next15 的 `params`/`searchParams` 须 `await`（Promise）。
- 数据访问：`lib/prisma.ts` 单例 PrismaClient；`lib/auth.ts` 鉴权（Bearer 优先，角色以 DB 为准）；
  `lib/adminSession.ts` 管理后台 SSO；`lib/catalogSync.ts` 书库同步。
- 数据库：Prisma 6 + Neon（库名 chonglang）。模型见 §3.4。
- ⚠️ Vercel 打包坑：路由 500 时检查 next.config.mjs 是否设
  `serverExternalPackages: ["@prisma/client", ".prisma/client"]`（章评 500 即由此修复）。

## 3.3 后端路由分组地图（app/api/）
- auth/        ：anon（设备匿名登录）/login/me/register
- users/[id]/  ：资料 + block/booklists/bookshelf/follow/followers/following/posts
- bookshelf/   ：书架增删
- booklists/   ：书单 + collect/items/report
- books/[src]/[id]/ ：书籍详情 + chapters/[chapterId]/(comments|segments) + characters + comments + **segment-comments（跨章段评聚合）**
- comments/[id]/ ：章评/段评 点赞/举报（parentId=楼中楼）
- community/posts/ ：书友圈动态 + like/report/comments + hot-posts/hot-booklists
- characters/[charId]/ ：角色 + heart/tags/comments（角色互动）
- catalog/     ：categories/seed/sync（自有书库）
- ratings/ votes/ leaderboards/ ：评分/投票/榜单
- progress/ reading/ ：阅读进度 + 阅读 session/stats
- sync/ annotations/ ：云同步 + 标注书摘
- ads/ attribution/ ：广告归因
- home/ health/ cron/ cover/ ：首页聚合 / 探活 / 预热 / 封面代理
- admin/      ：管理后台全套（announcements/books/characters/comments/community/config/posts/session/sso/stats/users）

【阅读内核】
- 连续滚动 / 翻页 / 单章滚动 三种模式；无缝连续阅读；离线章节缓存；目录抽屉(TocDrawer)。
- 章评/段评：正文不入库；评论锚定章节或段落+段内偏移+引用快照；内容寻址定位（容忍书源段落重排）。
- 段评入口：阅读器菜单「段评/全部段评」+ 长按选区「评」工具条；v0.15.7 起彻底废除段落末 💬N 气泡与下划线标记，正文不再预留右侧 padding，保证完整填充。
- 楼中楼：Comment.parentId 自关系，章评/段评均支持嵌套回复。
- 段评独立全屏页：跨章聚合全书根段评（章节标题+引用快照+楼中楼数+相对时间），点开复用段评线程。

【内容获取】
- 书城首页（Hero+热度轮播）+ 书库（搜索/分区/热榜/月票/最新）；书籍详情；角色详情。
- 书架（Room 本地）；书单（收藏/书单内加书）；UID 书号识别。

【社区】
- 书友圈：发图文动态、评论（已修键盘遮挡）、点赞、举报；热门动态/书单。
- 角色互动：比心（可取消）/标签墙（共建+投票去重）/角色讨论。
- 创作者中心（内嵌 App，仅 admin）：角色录入 / 书籍元数据编辑 / 公告管理。

【能力模块】
- 听书 TTS：逐句朗读+章末续读+语速调节+选中段落从此处听+暂停续读+当前句高亮。
- 护眼显示：蓝光过滤+连续阅读休息提醒。
- 创意工坊（插件化）：插件广场四 Tab + 划词标注 + 书签合集 + 插件可点开/停用 + 制作 Tab 自定义。
- 标注/书签/书内搜索 + 跨设备云端同步（LWW 冲突）。

【账号与平台】
- 三档账号：guest(设备匿名) / user(邮箱) / admin(youe@163.com) ；游客可云同步，注册升级本机账号。
- 管理后台 SSO：App 内一键进网页管理台（短 token→cookie，免二次登录）。
- 广告归因（Ad* 模型）、阅读统计、榜单、公告。

【分发】
- 在线更新：GitHub raw lan-update/version.json + APK（多通道 fallback：raw→jsDelivr CDN）。

1. 【最高红线】主站 novel-site（v8.8.1）永不改动；后端不碰主站库/表/凭据；不建正文/章节表。
2. 【正文不入库】小说正文只活书源 API；后端 Comment 只存锚点(章节/段落/偏移)+引用快照，绝不存正文。
3. 【发布前必核验 APK 进 main】`.gitignore` 忽略 lan-update/*.apk；每次发版必须
   `git add -f lan-update/surf-reader-X.apk` 后 `git ls-tree main lan-update/ | grep <apk>` 确认 blob 进 main。
   漏发 = 版本线断裂 = 用户拉到该版本下载 404（0.15.4 曾因此断裂，0.15.6 修复）。
4. 【ModalBottomSheet 内输入框必加 imePadding()】MainActivity.enableEdgeToEdge() 下，
   sheet 不会自动让出键盘高度（书友圈评论框曾被压住，0.15.4 修）。
5. 【段评气泡永远在 Text 容器外侧】anchor 贴段评段落右外（Text end-padding 区域内），
   绝不锚在文字字符上（0.15.5 修气泡挡字）。
6. 【SSH push 用绝对路径 key】`GIT_SSH_COMMAND="ssh -i /c/Users/Administrator/.ssh/xiaoswz_deploy ..."`
   （安卓）/ `xiaoswz_backend_deploy`（后端）。`~/.ssh/...` 在 GIT_SSH_COMMAND 不展开 → Permission denied。
   github.com:443 被屏蔽，只能走 SSH(22)。
7. 【密钥不入仓】所有 token/密码/连接串只在 ~/.workbuddy/MEMORY.md 与本地环境变量，绝不计入 Git。
8. 【构建产物在 builds/app_N】build.gradle.kts 用 .build_seq 自增序列号输出到 builds/app_<N>；
   产物 = builds/app_<N>/outputs/apk/release/app-release.apk（非 app/build/）。release 复用 debug keystore。
9. 【沙箱 git 网络不可信】判定推送成功必须事后 `git ls-remote origin main` 拿远端真值，勿信 fetch 旧值。
10.【Vercel CLI】用 `/c/Users/Administrator/AppData/Roaming/npm/vercel --token <token> --yes`，
   勿用 npx（卡 npmmirror）；本地代理偶发宕机时 `unset HTTPS_PROXY HTTP_PROXY` 直连。

# 沙箱需 dangerouslyDisableSandbox；JAVA_HOME 指 Android Studio 的 JBR

## 7.2 发版步骤
1. 改 app/build.gradle.kts 的 versionCode(+1) / versionName，并在注释写本次要点。
2. 改 lan-update/version.json（versionCode/versionName/apkUrl=surf-reader-X.apk/notes）。
3. 构建（§7.1）→ 复制 APK：
   cp builds/app_<N>/outputs/apk/release/app-release.apk U:\xiaoswz-reader\lan-update\surf-reader-X.apk
4. 提交（必须 -f 加 APK，并核验进 main）：
   cd /u/xiaoswz-reader && git add -A && git add -f lan-update/surf-reader-X.apk
   git commit -m "X.Y.Z ..." && git ls-tree main lan-update/ | grep surf-reader-X.apk   # 确认非空
5. SSH push 安卓 + 核验远端：
   GIT_SSH_COMMAND="ssh -i /c/Users/Administrator/.ssh/xiaoswz_deploy -o StrictHostKeyChecking=no" git push origin main
   GIT_SSH_COMMAND="ssh -i /c/Users/Administrator/.ssh/xiaoswz_deploy -o StrictHostKeyChecking=no" git ls-remote origin main
6. 后端若有改动：commit → SSH push 后端 → vercel deploy --prod（见 §7.4）。
